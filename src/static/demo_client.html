Embeddable AI Customer Chatbot

This webpage represents any external client website (Shopify, WordPress, Webflow, or a custom site). The AI chatbot below is 100% decoupled and runs completely isolated in a Shadow DOM via a single script tag!

How This Website Connected The Bot:

Simply pasted this script tag into the HTML:

<script 
  src="/static/widget.js" 
  data-project-id="technest-default" 
  data-api-url="">
</script>
